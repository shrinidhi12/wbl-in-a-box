# WBL in a Box

A work-based learning (WBL) enablement platform for high schools: a guided journey that helps a school recruit local employers and move them up five levels of engagement, from a first conversation to formal internships.

- **[app/](app/)**: the clickable prototype (Vite + React + TypeScript). See [app/README.md](app/README.md) to run it, and [app/DEMO.md](app/DEMO.md) for a 5-minute demo script.
- **[PROMPT.md](PROMPT.md)**: the original Claude Code prompt used to build the prototype.
- **[GAPS.md](GAPS.md)**: product decisions, deferred items and open risks.

> Prototype only: mock data, no backend. Labor-market figures are illustrative samples, and the Colorado paperwork checklist is not legal advice.
